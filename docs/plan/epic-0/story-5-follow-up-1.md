**Proposed; NOT READY.** A source-only checkpoint makes the [EF0 oracle](../../ef0-baseline.md) reproducible. It does not close [Story 5](story-5.md) or authorize content work.

## Tests first

- In `tests/generation-fixtures.test.ts`, retain core named cases, omitted seed, retry/exhaustion and mutation sensitivity. Extended tests cover all 103 primary and nine supplemental inputs in frozen order. Test that a changed byte, missing, duplicate or reordered entry fails; filtering tests must not materialize either corpus at import time.
- In `tests/ef0-tooling.test.ts`, exercise archive identity, exact manifest and compressed-tree verification, wrong root/revision, corrupt or extra file and refusal to overwrite evidence. From a clean checkout with **no** `test-results/`, native tests must verify the candidate offline, not skip, download, or bless its outputs.
- Extend `tests/generation-pair-analysis.test.ts` before collection: synthetic paired blocks pin boundary equality, over-budget and inconclusive decisions; reject wrong identities, incomplete blocks, bad telemetry and second attempts. Synthetic measurements never count as evidence.

## Final latency decision (after checkpoint only)

- Predeclare one diagnostics-off A/B campaign in `docs/ef4-results.md` before sampling. Adapt `tests/measure-generation-paired.ts` and its pure analyzer for historical A versus checkpoint B, each with its own verified lock/deps; identical harness, Node, flags, host and five EF0 seeds. Freeze hashes, ten original **unrounded** allowances, warmup/rotation counts and seeded balanced order (eight AB, eight BA). Use 16 separated paired blocks, one fresh process per arm, 100 measured rotations per process; 180 s/process, two active hours, seven elapsed days, one campaign. No preliminary A/A gate or manual bookings: automate spaced windows with predeclared interval, quiet thresholds and deadline; require operator coordination only if isolation actually needs it.
- Freeze → collect → replay → review; invalidity after start is terminal, never replace a pair. Record actual timestamps, commands, per-rotation samples, process identities, CPU/governor, interval CPU idle/load, competing processes and temperature before/during/after arms. No simultaneous build, browser or profile. Write once under ignored `test-results/`; retain partial failures. Missing telemetry, drift, dependence between blocks or unmatched control (median control outside historical midpoint ± original addition) prevents clearance.
- For each seed and process median/nearest-rank p95, sort the 16 **within-block B−A** differences. Report spread and one-based order bounds `[d5,d12]`; pass only if every upper bound is within its frozen addition. Any lower bound above allowance is an overrun; crossing the limit is unresolved. Do not pool rotations as independent observations, trim outliers, extend sampling or relax limits.
- Publish human-authored results and replay instructions. Reconcile every separate Story 5 correctness, trace/recovery, resource, allocation, startup, animation and root/Pages gate with the exact candidate; rerun stale or unmatched checks. Only complete passing evidence **and independent READY review** clear EF4. Otherwise retain NOT READY, identify the unresolved endpoint or prerequisite and stop.
